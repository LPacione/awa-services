Humedad ascendente

05 etapas de obra

¿Problemas con la humedad? ¿Ya probaste con la ventilación por capilaridad?

La humedad que sube por la base no se corrige pintando encima. Se abre el pie del muro, se coloca un zócalo ventilado y se recompone el paramento.

Consultar

Registro de ejecución

Deslizá las etapas

  1. Picado de base

    Se retira el revoque de la base hasta dejar la mampostería a la vista.

  2. Nivel y replanteo

    Se controla la horizontal con nivel a lo largo de todo el paramento.

  3. Montaje del perfil

    Se fija el perfil metálico que va a recibir el zócalo ventilado.

  4. Fijación con mortero

    Se rellena con mortero para integrar el perfil al muro.

  5. Rejilla y terminación

    Se coloca la rejilla perforada y la base del muro queda ventilada.

Tocá cada foto para verla completa. Registro de ejecución sobre muro de mampostería: el sistema se define después de relevar cada caso.

Cómo se trabaja

Del primer mensaje a la obra terminada.
